## 🚀 Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm start
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build & Deploy

To build the project for deployment (e.g. Vercel, Netlify, GitHub Pages):

```bash
npm run build
```

The optimized static production files will be output to the `build/` directory.
